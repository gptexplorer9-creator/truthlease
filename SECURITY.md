# Security policy

## Supported version

TruthLease is an early release candidate. Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities, credential exposure, approval bypass, provenance forgery, SSRF, or mutation-boundary defects.

Use GitHub's private vulnerability reporting flow in the repository Security tab. Include:

- the affected commit and file;
- reproduction steps using synthetic data only;
- expected and observed authority boundaries;
- impact and any safe mitigation.

Do not include live credentials, customer data, private TrueForge sessions, or production database contents. We will acknowledge a complete report through GitHub and coordinate disclosure after a fix is available.
